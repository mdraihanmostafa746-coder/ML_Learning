### ENCODING CATEGORICAL VALUES ###

*  ECV : 
    |
    |--> i. Label Encoding 
    |
    '--> ii. One Hot Encoding

* Why we need Encoding Categorical Values..???


      We need to encode categorical values because most machine learning algorithms rely on mathematical equations and numbers. 
      They cannot process text data or words like "Red" or "High" directly. Encoding translates these text categories into a 
      numerical format while keeping the meaning safe.  
    
    i. Label Encoding :
            |
            |
            '-->
                Lett's : 

                    Gender              Encoded

                    Male                0
                    Female              1

            Tt's convert category into numbers.

    ii. One Hot Encoding :
            |
            |
            '--> Let's: 
                    City : Delhi, Mumbai, Chennai, Kolkata 
                        It's converted into : 
                                |
                                |
                                '--> City Delhi, City Mumbai, City Chennai, City Kolkata

### Feature Scalling : 

            a data preprocessing step in machine learning that adjusts the numerical ranges of independent 
            variables so they share a common scale, preventing features with large values from dominating 
            models that rely on distance or gradient calculations.
