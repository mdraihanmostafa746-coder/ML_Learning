#### STANDARD SCALER SUM ###

Formula for Standered Scaler (z) :

                   x - μ
            z =  ---------
                    σ

                Where, 
                   z is the new scaled value
                   x is the original data point
                   μ is the mean of the feature values
                   σ is the standard deviation of the feature value

Example : 

         'StudyHours' : [1, 2 ,3, 4, 5]

            x = 1
            μ = (1+2+3+4+5)/5 = 3
            σ =>

                1. (1-)^2 = 2
                2. (2-3)^2 = 1
                3. (3-3)^2 = 0
                4. (4-3)^2 = 1
                5. (5-3)^2 = 2

                Average of this variance : 

                                    (4+1+0+1+4) / 5 
                                            = 2

                The root of 2 = 1.41

              = 1.41
              σ = 1.41

            z = ( x - μ) / σ
              = ( 1 - 3) / 1.41
              = -1.41 Ans
